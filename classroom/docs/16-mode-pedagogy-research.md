# 两种玩法，两种学习：故事版与实验版教学研究

编制与访问日期：2026-10-10。适用项目：《曹冲称象：一线之差》。本文补充 [10-learning-design-research.md](10-learning-design-research.md)，专门解决两种模式只有难度差、没有学习方式差的问题。以下交互、字数和验收规则均为项目设计推导，不代表课程标准为本产品作过认证，也不代表已经取得课堂效果证据。

## 一、这次修改应改变什么

**故事版让学生进入故事、看懂动作、说清过程；实验版让学生提出问题、安排比较、用自己的记录说明结果。** 两版可以共用码头、人物和称象原理，但不能要求学生沿同一条流程做相同的事情，再用大数、术语和更多按钮区分。

语文课标第一学段重视借助图画理解、听看后讲述；第二学段进一步重视具体、生动的叙述和交流。科学课标三至四年级侧重引导下的简单探究，五至六年级进一步要求设计控制条件的实验并反思报告。数学课标以“曹冲称象”为例，关注称量、等量推理及各部分与总量的关系。这三条依据支持不同的学习组织方式，而不是不同的计算负担。[语文课标第 8、10 页](https://www.ictr.edu.cn/Uploads/File/2022/04/28/3.%E4%B9%89%E5%8A%A1%E6%95%99%E8%82%B2%E8%AF%AD%E6%96%87%E8%AF%BE%E7%A8%8B%E6%A0%87%E5%87%86%EF%BC%882022%E5%B9%B4%E7%89%88%EF%BC%89.20220428161048.pdf) · [科学课标第 12 页](https://www.ictr.edu.cn/Uploads/File/2024/09/18/10.%E4%B9%89%E5%8A%A1%E6%95%99%E8%82%B2%E7%A7%91%E5%AD%A6%E8%AF%BE%E7%A8%8B%E6%A0%87%E5%87%86%EF%BC%882022%E5%B9%B4%E7%89%88%EF%BC%89.20240918113747.pdf) · [数学课标例 15，第 106 页](https://www.pep.com.cn/xw/zt/rjwy/yjkb2022/202205/P020220512583134605579.pdf)

### 两版必须看得见的差异

下表是本项目建议，不是课标原文。

| 维度 | 故事版：二至三年级 | 实验版：四至六年级 |
|---|---|---|
| 学生身份 | 曹冲身边的小伙伴，帮忙观察、留线、记批次，最后把办法讲给新伙伴听 | 自己做决定的小研究员，检验“水线一样，就能知道大象多重吗” |
| 驱动问题 | 大象这么大，小秤怎么帮上忙？ | 同一条水线，什么时候能说明两次装的东西一样重？ |
| 开始方式 | 以大象来到码头的场面进入，接到一个具体请求 | 用一张四步图快速唤起故事，马上选一个要研究的问题 |
| 主流程 | 入场看象 → 合作称象 → 发现少了一个人 → 补好办法 → 四格讲述 | 选问题 → 先猜 → 定比较办法 → 做两次并留记录 → 看差别 → 解释和再试 |
| 必做动作 | 看图找位置、选一句恰当的话、完成关键动作、按顺序讲述 | 选要改变的条件、说明哪些不动、保存可比较的两次记录、用记录支持结论 |
| 提示方式 | 伙伴短句、局部指示、可听对白；一次只说下一件事 | 先问“怎样才能比得清楚”，再给提示；可以随时回看计划与旧记录 |
| 数字处理 | 图签和一批一次，系统帮忙合计；不把大数加法设为故事出口 | 关注数值从哪里来、少算或多算哪一份；先辨关系，再计算 |
| 犯错后的反馈 | 画面显示没做成的事，伙伴说出具体问题，允许立即改 | 保留原猜想和原记录，提示比较是否成立，允许用新试验修订 |
| 惊喜来源 | 自己选的词让动作发生；四次行动变成自己的连环画；伙伴用学生的话复述 | 看似相同的水线出现不同结果；一次只改一处后找到原因；自己设计的反例推翻过早结论 |
| 完成作品 | “我和曹冲称象”四格故事，含自己的连接词和一句解释 | “我的发现”实验卡，含问题、原猜想、两次记录、结论与还想检验的问题 |
| 教师看什么 | 能否按顺序讲清关键动作，能否指出为什么留线，是否回应伙伴的问题 | 两次比较是否只改所研究的一项；结论是否有记录支持；是否说清适用条件 |

四年级进入实验版时，提供已经排好一半的比较卡；五六年级可以自己挑条件和设计记录。这是对同一个实验版调整支架，不必新增第三个产品模式。年龄标签表示本项目的体验建议；教师可按学生阅读和探究经验选择。

**反例验收：** 把画面颜色、标题和年级标签遮住，仍应能从学生正在做的事辨认两版。若两版都主要是“照提示点按钮—搬石头—填数字—看同一个总结”，分层仍未完成。

## 二、已核查的一手依据与使用边界

### S16-1　教育部《义务教育语文课程标准（2022年版）》

原文由[教育部课程教材研究所公开提供](https://www.ictr.edu.cn/download_center/ywjy.html)。本次下载官方原件，并视觉核对纸面第 8、10 页（PDF 第 15、17 页）。第一学段强调借图阅读、交流人物事件感受、听看后讲述；第二学段强调把握大意、具体生动地讲述和倾听回应。**项目推导：** 故事版的出口应是学生自己的讲述，不能只给系统自动拼好的答案；词语学习嵌在可见动作与真实交流中。

### S16-2　教育部《义务教育科学课程标准（2022年版）》

[官方原件](https://www.ictr.edu.cn/Uploads/File/2024/09/18/10.%E4%B9%89%E5%8A%A1%E6%95%99%E8%82%B2%E7%A7%91%E5%AD%A6%E8%AF%BE%E7%A8%8B%E6%A0%87%E5%87%86%EF%BC%882022%E5%B9%B4%E7%89%88%EF%BC%89.20240918113747.pdf)。本次下载并视觉核对纸面第 12 页（PDF 第 19 页）。三至四年级涉及引导下提问、简单计划、观察记录与解释；五至六年级进一步涉及控制变量、比较结论与假设、呈现并改进报告。**项目推导：** 实验版需要学生参与决定怎样比较，至少留下两份可比较的记录；仅反复调整到正确水线，不能代替实验设计。

### S16-3　教育部《义务教育数学课程标准（2022年版）》

[人民教育出版社提供的原文，例 15，第 106 页](https://www.pep.com.cn/xw/zt/rjwy/yjkb2022/202205/P020220512583134605579.pdf)。该例直接使用称象故事，引导认识质量、称量工具、等量及总量与分量的关系，并联系实际称量。**项目推导：** “换一种能分开称的东西”“每一批都算上”比把数字加大更能体现进阶。小数值模型同样可以承载复杂推理，不以口算速度替代科学解释。

### S16-4　人民教育出版社《在课程视野下精准定位语文要素的落实》

[官方页面，2019-05-17](https://www.pep.com.cn/xw/zt/hd/zjywjytbskjc/201905/t20190517_1938340.html)。这是围绕当时教材的教学论述，举称象步骤串联讲述的例子，讨论先讲清部分、再完整讲述的支架。**项目推导：** 四格故事分段积累、最后合成，比末尾突然要求完整长段复述更合适。该文章不是随机对照研究，也不是当前教材目录证明。

### S16-5　人民教育出版社《曹冲称象》朗读页

## 三、三种与知识紧密相连的趣味互动

以下均为原创产品方案；“有趣”体现在学生发现、表达和验证，不另设与称象无关的积分小游戏。

### 互动一：让一句话动起来（故事版）

**学生任务：** “曹冲说得太快了。请你把这一步说清楚。”在“沿着／离开”水面、“船身下沉／浮起”等短句卡中作选择，再点画面相应位置。句子与画面紧挨着；“舷”首次出现时标读音并指到船边。

**可见后果：** 选择的词决定回放中的动作。位置不合适时，笔留在岸边或线与水面错开，曹冲问“船一动，这条线还能跟着走吗？”学生修好后，线随船一起移动。不能把错误动画做成可保存的正确记号。

**留下的作品：** 一张带自己选词的动作卡，收入故事连环画；完成动作后补一句“我把线画在……，因为……”。教师可听学生说，不要求所有儿童键入长句。

**惊喜与边界：** 学生的话真正指挥画面，词义有了结果；不以反应速度计分，不因读音帮助扣分。两种恰当表述均应接受，如“船边”和已讲解的“船舷”，不把措辞唯一化。

### 互动二：给没看见的伙伴讲一讲（故事版结尾）

**学生任务：** 新伙伴来晚了，只看到码头上的石头。学生从自己过程里取得的四张图卡排出故事，选“先、再、接着、最后”等连接词，说给伙伴听。

**可见后果：** 漏掉留线，伙伴追问“装到什么时候停呢？”先称完又额外加石，伙伴问“后来加的这一份，也称过了吗？”追问针对当前排序，不统一弹出“答错了”。允许把图卡取回、重新排列。

**留下的作品：** 学生完成的四格故事与一句自己的解释。图序正确只记“排好顺序”；实际口述由学生自检或教师记录，不自动标成“会复述”。

**惊喜与边界：** 卡片像小书一样翻开，回看的是本次选用的材料和真实行动。用密封袋完成的路线不能在作品里变成石头；修正船工差别的路线要留住这件事。结尾可以收起词语提示再讲一遍，但不强制所有学生背诵。

### 互动三：两张照片，查出一个原因（实验版核心）

**学生任务：** 先选一个问题，例如“船工下船后，装到原来的线还需要一样多的石头吗？”学生安排第一次和第二次：决定只改变什么，将同一艘船、平稳水面等条件放在“不改变”栏，再留下原猜想。

**可见后果：** 两次操作各留一张带水线、人员、替代物总量和是否触底的记录卡。学生把两卡并排观察。若同时换船、换人，系统不把结果解释成单一原因，而提示“这次有两处变了。你想先查哪一处？”允许先保存这次记录，再做可比较的一组。

**留下的作品：** “我改了……／没有改……／看到……／所以在……条件下……”的实验卡。可把船工请回去再试，用第三条记录检验解释，而不是点“重新验证”就自动正确。

**惊喜与边界：** 让学生先看到“线一样，石头却更多”的冲突，再自己找到少了的人。加入新挑战时倒转方向：第二次多一个人，石头应少一份，不能仍套用“每次减去 60”的口诀。数字可很小，推理不能省。若只点击了两次而条件无差别，应显示重复记录，不冒充新的比较证据。

## 四、文案规范：教材般清楚，伙伴般亲切

以下是产品编辑准则，字数为排版目标，不是课标规定。

1. **先说对象和动作。** 让学生知道看哪里、做什么，再解释原因。避免“进行验证”“完成证据闭环”等抽象动词。
2. **一句只推动一步。** 主任务通常一至两句，每句约 12—24 个汉字；必要原因可另起一句。不能为了短而丢掉“同一艘船”等成立条件。
3. **名词前后一致。** “记号线”指画在船上的线；“水面”指眼前水；“石头总重”与“大象多重”分开说，不能混用。
4. **生词放到实物旁。** “船舷（xián）：船两边的边缘”出现时指向画面；学习后可继续用“船边”帮助低年级理解。不一次给整屏拼音。
5. **按钮说接下来会发生什么。** 用“留住这次记录”“请船工回船”，少用“确认”“应用”“提交”。
6. **反馈先给事实，再给可做的事。** 指出哪一批、哪条线或哪个人发生了变化；不用“太粗心”“你真聪明”等给儿童贴标签的话。
7. **问题是真问题。** 保留合理猜想与解释空间，不让唯一正确选项明显比其他选项长、具体、礼貌。
8. **活泼来自场面。** “咦，船边的线露出来了！”比密集感叹号、拟声词和“超级任务”更有画面感。声音只作辅助，不影响静音理解。
9. **不预告尚未取得的发现。** 动手前说“试试看”，动手后才引用真实结果；不能把“石头代替大象”的解释提前塞进所有选项。
10. **鼓励说自己的话。** 可提供开头，但不把整句正确解释预先填好。允许口述与图卡支架；教师查看学生实际表达，而非点了多少按钮。

### 十条短句与反馈改写例

左栏是应避免的表达方式，并非全部逐字摘自现有代码；右栏可直接用于界面或对白。

| 场合 | 应避免 | 建议文案 |
|---|---|---|
| 接任务 | 完成等量代换任务 | 大象上不了小秤。你愿意和我一起想办法吗？ |
| 选参照 | 选择合理参照物 | 这条线画在哪儿，才能跟着船一起走？ |
| 船还晃 | 环境稳定性不满足要求 | 船还在晃。等它稳一稳，再画线。 |
| 观察水线 | 载荷发生变化 | 拿下一块石头，船身浮高了一点。你看见了吗？ |
| 记账未称 | 当前批次未经测量 | 这筐还没称。先放到秤上看看吧。 |
| 重复记账 | 检测到记录异常 | 第三筐记了两次。对照筐上的图签，改一改。 |
| 少了船工 | 固定载荷不一致 | 看看前后两张图：船上的人一样吗？ |
| 设计实验 | 请进行控制变量实验 | 这次只改哪一处？其余地方先不动。 |
| 结论不足 | 证据不足，无法通过 | 这两次，船和人都变了。先只改一处，再比一比。 |
| 纠错后 | 恭喜！你真是科学小天才 | 你找到了多记的那一筐，还把账改好了。把发现告诉大家吧。 |

状态反馈必须跟实际动作一致。例如学生放上石头时不能出现“拿下一块”；第二筐出错不能固定说“第三筐”；系统没有记录两次试验时不能说“这两次”。

## 五、实施与验收用的五个问题

1. **两版的第一项主要任务不同吗？** 故事版应很快进入人物求助与可见动作；实验版应很快进入自己选择的问题和计划。
2. **低年级能不靠算大数讲清办法吗？** 若数字遮住后任务无法继续，应补图签、分批对应和系统合计。
3. **实验版的学生真的决定过比较办法吗？** 至少保留一个由学生选择的改变条件，以及两次真实记录；系统自动替学生设好全部条件不能算独立设计。
4. **结束时拿到的作品不同吗？** 故事版应是可复述的连环画，实验版应是可质疑、可复做的记录与结论；不能只换一个结业称号。
5. **反馈是否帮助下一步而不是替学生答完？** 用错误猜想、重复记账、同时改变两条件各试一次；看学生是否有机会改，旧判断是否还在，最终作品是否反映自己的过程。

通过这些产品检查，只能说明学习任务和交互已按设计实现。儿童是否觉得有趣、措辞是否易懂、是否会迁移，仍需观察相应年龄学生真实使用；不由自动化通关结果代替。
