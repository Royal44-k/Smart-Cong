# 制作设计书 · 课堂交付版1.1

《曹冲称象：一线之差》把同一个称象故事组织为两种学习经历。故事版的孩子是曹冲的小帮手，通过看、玩、找、贴、讲，最后做一本四格小书。实验版的孩子是研究员，选择问题、安排两次比较、解释条件变化，再完成书箱新问题与实验报告。

核心转折是“阿舟去岸上取秤”。水线相同，船上的人却变了。故事版用人物和石堆的变化理解原因，实验版可恢复条件或处理差额。猜对数字不代替有效比较；暂不确认、修改记录都是可行分支。

|交付范围|本版内容|
|---|---|
|故事版|独立情节任务、图案称重条、四格排序、动作词、个人讲述|
|实验版|三选一研究问题、计划、实际A/B对照、称象数值推理、书箱迁移|
|共同底层|自由漂浮与水线模型、四种结尾、保存/刷新、打印/导出、声音与媒体回退|
|制作资产|17张采用图、19镜制作卡、38句对白、19段朗读、38个逐句WAV、19份VTT|
|教学与生产|完整剧本、分支条件、课案、学习单、评价、研究依据、镜卡、提示词、回片表、测试证据|

视频由用户选择的外部工具制作，未包含实际成片。其余课堂体验和生产前期在本项目内可独立使用。

沿用《潮起虎门》的研究→学习目标→分支剧本→状态规则→分镜→场景图→互动实现→内容与技术验收流程。每个互动都对应可见学习证据；不以点击速度或结尾等级替代学习评价。两版差异见[设计矩阵](17-mode-redesign.md)，可执行故事见[分支剧本](02-branching-script.md)，逐镜生产见[导演手册](13-director-production-bible.md)。
