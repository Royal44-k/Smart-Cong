# v1.7 学生主导展示、检索练习与证据表达研究

研究日期：2026-10-12。适用范围：《曹冲称象：一线之差》故事版（二至三年级）与实验版（四至六年级）的最终学习成果展示。本轮只为已有成果增加学生主导的讲述方式；不增加强制学习任务，不改学习状态，不把通关、翻页或展开提示当作掌握。以下方案是依据来源形成的项目设计推论，不是已完成的课堂效果验证。

## 结论

故事展示宜让学生自己逐页翻看已有四幅图，自主隐藏或显示已有学生图注及参考提示；实验展示宜让学生指着真实问题、猜想、A/B记录、观察、修订、称象结局与书箱迁移记录讲述。界面负责呈现已有证据，学生负责组织解释。**自我解释不等于显示系统答案，也不等于照读一段自动生成的“我的发现”。**

## 五条有边界、可测的原则

### 1. 让学生控制四页节奏，并保留随时求助的入口

依据：R1。在最终成果中提供“我来讲故事”。进入后保持四页既有图片和次序，由学生主动按“上一页”“下一页”或页码翻页；不自动轮播、不倒计时，不要求讲满时长。图片本身可以作为回忆线索，因此宜称“看图讲述”，不声称完全脱离提示的自由回忆。

学生可以先收起文字，再按需要分别查看“我写的话”和“参考提示”。原图注已经存在时原样呈现；没有图注时不补写。若参考内容实际是一段完整讲法，应标“参考讲法”，不能仅称“小提示”而掩盖其答案性质。学生可从“带着文字讲”逐渐转为“看图讲”，无需经过系统判定。

**适龄文案：**“这一页，你想怎么讲？”“想一想，再慢慢说。”“看看我写的话”“看看参考提示”“收起文字，接着讲”。

**可测边界：** 共四页；首尾页不会越界；连续等待不自动翻页；可往返任意页；收起再展开保留图注原文；隐藏文字只改变呈现，不清空内容或写入完成标记。独立切换学生文字与参考内容时，来源标签始终正确。

### 2. 问关系，给学生组织解释的空间

依据：R2。展示中可提供一个简短问题供学生选择使用。问题邀请学生解释做法与理由，不把一整段答案自动填到“我的讲述”里。故事四页可对应“遇到什么难题”“记号记住了什么”“石头放到什么时候”“怎样知道最后的重量”。二至三年级可以指图和口述，无需输入、录音或语音识别。

实验版的提示宜连接实际证据，例如“这两次哪里相同，哪里不同？”“哪条记录让你改变了想法？”允许学生先说不完整的解释，再看参考、重新组织语言。参考讲法是学习资源；学生点击查看、朗读或自报“讲完了”，都不是系统已经听到并评判了自我解释。

**适龄文案：**“指一指图里的线索，说说你为什么这样想。”“想补一句吗？可以回到上一页。”“参考可以帮你想一想，再用自己的话讲。”

**可测边界：** 所有系统生成文字带参考或记录说明身份；没有保存学生表达时，不出现引号中的伪造学生原话；展示不自动生成“我明白了”“我证明了”或“已掌握”。教师可听学生能否连接做法和理由；软件不能从页面停留、点击次数或读完参考推出这一结论。

### 3. 实验展示保留真实证据链与空缺

依据：R3。实验成果按“问题—原猜想—A/B记录—观察—修订—称象结局—书箱迁移”组织。这里的箭头是阅读顺序，不暗示研究只能线性发生，也不表示每一栏已经完成。实际保存内容与系统依据已有数值生成的客观记录说明分开标识；A/B是当时保存的记录，不应被当前可操作实验场景替换。

|已有内容|适龄标题或引导|真实性边界|
|---|---|---|
|question|“我想研究什么”|显示实际选择或记录的问题；缺失时显示尚未记录。|
|hypothesis|“我原来怎样想”|保留原猜想；不因后来的正确结果改写它。|
|A/B|“看看我的两次记录”|同时标A、B、条件、单位及已保存观测；缺一份就明确缺失，不用当前值补齐。|
|observation|“我看到了什么”|只呈现实际记录；系统说明不能伪装成学生原话。|
|revision|“我后来怎样想”|显示真实修订；没有修订不自动写成“我的猜想得到证实”。|
|称象结局|“这一次，称象结果怎样”|展示实际结果和已有条件说明；未完成不生成成功结局。|
|书箱迁移|“换成书箱，我怎样想”|展示已有判断、数值、反馈状态或留白；标准解答单独标参考。|

**适龄文案：**“这部分还没有记录，可以先讲已有的发现。”“指一条记录，说说它支持你的哪个想法。”

**可测边界：** 用无记录、部分记录、完整记录三类存档检查；每个展示值都能追溯到真实保存字段或明确标出的系统计算。缺失值不转换为0，错误回答不被替换为正确答案；未保存的草稿和正式记录若同时展示，必须明确区分。渲染路径不能修改任何已有记录。

### 4. 把结局和迁移作为可讨论证据，不作为掌握徽章

依据：R2、R3。本轮的学习机会是学生把实际记录与结论联系起来。可邀请学生从A/B指出比较条件，再联系称象方法；书箱展示则邀请说明砝码所替代的对象和工具份额。若当前题设是同一艘船、同水线、320克砝码替代书箱与20克工具，则系统参考可解释320－20＝300克，但必须与学生已有回答分开。

不要把“一样高的水线”泛化为任意不同船、不同水体或触底状态都等重；也不要因数字300正确就宣称学生独立理解了控制条件。学生看过完整答案后再复述可能有学习价值，但与独立迁移证据不同。上述判断供教师在交流中观察，本轮不新增评分、关键词匹配或能力标签。

**适龄文案：**“这两次能直接比吗？找一找没变的地方。”“这320克，替代了哪些东西？”“如果拿掉工具，只求书箱，还要想哪一步？”

**可测边界：** 结局失败、书箱尚未作答或回答错误时仍可进入展示；显示真实状态并允许学生讲述已有发现。翻完、查看参考、进入展示或退出展示均不将结果改成正确，不增加掌握分。展示若呈现标准算式，明确标为参考，而非“你已经解释了”。

### 5. 展示是可访问、可退出的只读视图

依据：R4及本轮“不改学习状态、兼容旧进度”的产品约束。入口、翻页、提示开关、返回使用清楚命名的原生按钮，键盘可到达并可激活；展开控件的 aria-expanded 与真实可见状态一致。当前页用“第2页，共4页”等文字说明，不能只靠颜色。没有悬停、拖动或手势才能完成的必要操作。

隐藏讲稿不等于隐藏图片的可访问说明。图片仍应有对画面事实的中性描述，供无法看清图片的学生参与；描述不宜偷偷塞入完整推理答案。真正收起的提示不能继续被读屏当作正文读取，也不能遗留可聚焦的内部控件。关闭展示后返回原成果位置，焦点回到入口或合理的原位置。

展示页码、提示显隐属于临时界面状态。无需给旧存档补“已展示”字段，也不应触发关卡提交、修订保存、实验重跑或迁移判定。旧存档字段缺失时通过只读回退文案处理，保持此前成果入口可用。

**适龄文案：**“开始展示”“上一页”“下一页”“第2页，共4页”“显示参考提示”“收起参考提示”“返回我的成果”。

**可测边界：** 仅键盘可进入、翻页、展开、收起、退出；按钮名称与展开状态相符；隐藏区不可聚焦。用同一份旧存档在进入前、翻页后、切换提示后、退出后比较学习数据，内容不变；刷新后旧进度仍正常。移动窄屏和长图注不遮住翻页、提示及退出按钮。

## 主要风险与核查要点

|风险|本轮处理|
|---|---|
|隐藏所有帮助导致低年级无从讲起|保留图片和短问题；提示随时可恢复；允许先指图、带文字讲，不奖励“从不求助”。|
|系统答案被包装成学生原话|学生图注、学生选择、客观记录、参考提示分开标识；缺失保持留白，不自动第一人称改写。|
|完成展示被解释为掌握科学方法|只表示视图操作；不写通过、熟练、已证明等学习评价；后续学习效果仍需实际观察或独立任务证据。|
|A/B摘要丢失条件，制造错误因果|保留两次原记录及条件；不能只展示一个水线差值或“成功”标签。|
|迁移答案被提前代填|学生已有答案与系统参考并列分层；看过参考后不宣称独立作答。|
|隐藏提示损害读屏使用，或只靠滑动翻页|区分中性图片描述与讲稿；检查焦点、按钮状态、隐藏内容及显式翻页按钮。|
|为展示补字段改变旧存档|只读容错；空、部分、旧版存档都可打开；比较进入前后学习数据，不制造新的必做流程。|

本轮验收应证明“展示由学生控制、内容来源真实、数据没有改变、交互可以访问”。它不能证明儿童已经形成自我解释能力或实现长期迁移；这些需要在真实交流与后续学习中另行观察。
