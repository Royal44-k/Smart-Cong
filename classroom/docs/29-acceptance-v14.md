# 课堂交付版 v1.4 验收

日期：2026-10-12。完整回归执行时间：2026-10-12T04:24:00.930Z。在v1.3基础上增加学生逐页表达与可选实验修理，完成视觉、键盘、保存、打印和生产衔接的润色。

## 本版结果

- 故事小书：4页静帧逐页翻看、可选160字图注、参考讲法和同桌追问。允许口述，空图注打印留白；不把系统参考句当成学生原创。
- 实验修理：3组可选控制变量任务，固定A、亲手改B、说明理由再检查。接受所有合法B，不自动修好，也不改正式A/B、猜想、结论和结局。
- 学习记录：图注、页码、修理前后条件可刷新恢复；完整、短练习与旧路线均能查阅和打印修理摘要。重摆只撤回当前组。
- 交互细节：中文输入不重绘失焦；保存受限不谎报成功；键盘完成后留在修理区；小屏聚焦控件避开伙伴。
- 视觉：延续既有美术；清除新区域与旧舞台样式冲突，修正选中态对比度与手机缩略图。角色透明悬停效果保留。
- 制作：19镜、38句对白、19音轨与字幕保持；新增4页讲述和3组修理的界面资源清单，C-V11与C-L02交互接出同步。

## 复验与使用

1. 双击“启动体验.cmd”，或运行npm start，打开本机4184端口。
2. npm test运行单元测试；npm run test:browser运行87项浏览器检查；node tests/workshop-touch-browser.mjs补验真实触摸。
3. node scripts/run-v14-verification.mjs生成完整日志与汇总；npm run build:production重建制作文件。
4. node scripts/verify-doc-links.mjs检查本地文档链接；node scripts/prepare-delivery.mjs重建交付清单；PowerShell运行scripts/package-v14.ps1生成新的包。打包脚本拒绝覆盖现有包。

学生运行只需Node.js服务与浏览器。开发验收环境另外使用Playwright及Microsoft Edge。已有v1.3进度可直接进入新讲述台或修理铺，无需清空记录；更早存档继续原来的主路线。

## 边界

视频仍由用户外部生成；本轮没有新增影片、配音或图像造型。[执行稿](28-workshop-production-v14.md)写明镜头停在哪里、界面怎样接棒、哪些实时内容不能烧进视频。未来回片后仍需检查真实编码、字幕与独立播放。

IAB自动化运行时不可用，本轮使用独立Edge上下文验证，未修改用户浏览器的学习进度。功能与规则测试不能替代真实班级效果研究；教师可使用[研究与观察建议](27-expression-repair-research-v14.md)收集学生原话及修订依据。

交付采用显式文件清单与SHA256校验，不包含密钥、node_modules、临时基线或弃用图片。v1.3及更早的压缩包保留。
