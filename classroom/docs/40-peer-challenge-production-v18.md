# v1.8 我出题，你来解：设计与制作执行稿

2026-10-12。用户要求主动增加有趣且有教育意义的互动，低龄文案具体、简短、活泼。本轮在完整学习成果页新增自编题与交棒，不替换原学习路线；学生可同桌轮流，也可自己玩。

## 设计选择

已有选择、拖曳、连线、拼图和教师预设小游戏。本轮增加的是学生设计任务、交给别人、解释做法的角色变化。故事以四幅图组织先后与理由，实验以不同工具安排练习数量关系。所有玩法可选，没有倒计时、积分或掌握徽章。

沿用故事青绿#234f46、暖纸#faf9ee、金线#b0924e；实验蓝#25566e、浅蓝#e8f0f3、墨色#203e50。宋体式标题用于画面与提问，微软雅黑/系统中文无衬线用于操作，等宽数字用于数值。桌面把题图与操作并列，手机上下排列；签名视觉是故事图上的纸帘与实验两次装载的对照。画面、人物和物品全部复用已采用素材，数学关系图不代替影视图片。

方案自检：不叠加另一个通用游戏积分面板；把新入口合入既有成果分享区域。制作界面、交棒屏、解题界面明确分开，避免一面出题一面漏出答案。所有控制有明确按钮，键盘与触摸等效，不增加拖动精度要求。

## 故事：藏起一幅图

出题人从四幅故事图中选一幅，点击准备好后进入交棒屏。解题者看前后画面，从打乱顺序的四张图中补回缺页。看不清或想不起来可掀开纸帘；这会留下使用提示的记录，不代替学生选择。图补对后再选择这一步的作用，避免理由提前暗示缺图答案。

|图|适龄标题|该步的作用|
|---|---|---|
|上象|请大象上船|看看大象在船上时，水面到哪里。|
|留线|在船身画线|记住刚才水面的位置，换石头时好比较。|
|换载|换上石头|让石头替大象，回到刚才的水线，还要核对人和物。|
|称量|分开称石头|每份称一次、记一次，再把重量加起来。|

选择错图时提示看前后两步，不自动换成正确图。理由选错说明应关注做法的作用。最后反馈只说明本题的画面和理由对上，不能说学生已经独立记住、已经掌握。

## 实验：换个条件，出一道题

可选砝码220/320/420克、工具20/40/60克，工具只在第一次、两次都在或只在第二次，共27种题设。出题阶段呈现题目卡，不表现为移动真实物体的动态实验。明确说明“每换一题，就换一箱书”；单题内两次是同一艘船、同一盆水、船身平稳、自由漂浮、同一道水线。

书箱+第一次工具=砝码+第二次工具；因此书箱重量=砝码重量+(第二次有工具−第一次有工具)×工具重量。三类题分别是减去、等于、加上工具重量。交棒后冻结题目，不允许解题时偷偷改条件。

解题者先判断书箱比砝码轻、一样重或更重，再自己填写克数；提示只提醒两次工具位置，不直接填数。反馈区分关系判断与计算，允许修订，不用“再试试”代替具体指引。完成后可对照本题的两次装载说明理由。

## 状态与记录

根状态仍为v3；learning revision6升级为7，新增peer.story及peer.lab。迁移保留原问题、猜想、图注、反思、首次结局、称象值与书箱旧回答；新玩法不加主线门槛。出题/交棒/解题进度可刷新继续，原结局不变。

最近六次实际核对分别按两版留存，保留原选项、原数值和是否看过提示，区分尚未对上/已经对上；空白不写成作答。同一答复重复按核对不堆叠重复记录。改题清除本题答案与过期成功，但保留此前核对。记录和打印只描述实际操作，不区分或推断是哪位学生作答，不记录姓名。

## 交互与验收

- 交棒页只显示交接说明，不泄漏被藏图或答案。
- 打开时停止伙伴朗读/媒体并取消在途请求；原偏好保留，退出不自动播放。
- 模态内Tab循环、Escape退出、焦点回入口；输入时不重绘整页，正确处理中文输入法与数字。
- 内容区独立滚动，标题/返回及关键动作可见；至少44px目标，覆盖320/390/768/1440宽度和降低动态。
- 故事四个藏图位置、错图、提示、理由、轮流及刷新；实验27种条件、关系与计算分开反馈、改题撤销成功、错误/空白/旧记录均需验证。
