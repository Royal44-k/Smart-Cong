# v1.3 互动说理、图像与视频衔接执行稿

日期：2026-10-12。以[导演手册](13-director-production-bible.md)、[分支剧本](02-branching-script.md)为主线。本次强化学习过程，不增加独立剧情镜头，不改变既有角色、核心数值和四类结尾。

## 两版怎样教

故事版用“看图—找线索—讲办法”，面向二至三年级。学生不需要输入2700等大数；船、水面与阿舟的实时图帮助他们说清比较条件。实验版用“提问—猜想—试验—观察—修订—迁移”，面向四至六年级；学生自己安排A/B、解释变化、核算人员差额，再解决书箱问题。称象练习保持较短的共同复习路线。

视频素材总量仍为19镜、38句对白、19段朗读、19份字幕；新增界面反馈用文字和可选伙伴朗读，不塞进固定配音。完整电影对白继续以[voiceover.csv](../media/voiceover.csv)为准，互动文案来源为[推理规则](../src/reasoning-state.mjs)与[界面](../src/reasoning-views.mjs)。

## 画面与道具连续性

- 采用新增[六件物品图集](../media/learning/gallery.html)，原图[CC-OBJECTS-v002.png](../media/learning/CC-OBJECTS-v002.png)，完整[提示词](../media/learning/prompts.json)、[尺寸与SHA256](../media/learning/catalog.json)。使用内置image_gen生成；3列×2行。学生界面用CSS取图，不将模型生成的字当作题目。
- 小船为开放木船，无船舱；书箱为浅纸盒加书；工具为短铅笔和两块木楔。工具总计20克、砝码总计320克由界面标注，不能按绘画数量推算每件重量。六件插画是操作符号；拍摄仍依各镜首帧和场记保持同一实物。
- 阿舟、水线图证复用真实船图，随当前状态绘制并作局部放大。不能用“阿舟固定在岸上的剧照”表示修正后的船上状态。
- A/B观察窗使用相同尺寸、机位、水面高度，图形从已保存的两次记录生成。左侧为B、右侧为A，均有文字标签；两端按钮可分别看完整A/B。金线/水线有文字说明，不单靠颜色。
- 图证、配对、拼图和打印小书始终取静帧。电影播放器在独立场景区。接入MP4后不能把带controls的视频放入按钮，避免播放被当成学生选择。

## 提示与回应

|学生动作|响应|教育目的|
|---|---|---|
|把石头形状当成重量线索|“石头堆得像大象，也不一定一样重。”邀请回看船和记号|区分外形与比较依据|
|找出阿舟还在岸上|指出与上象时不同，邀请请回船再看水线|证据与操作相连，不泛称“答对了”|
|A/B同时改变两项|指出比较不公平，要求把无关条件调回|让错误成为可执行修订|
|观察与船位不符|提示对齐同一条水面，再分别看A/B|引导观察，不替学生选答案|
|记录推翻最初猜想|肯定“根据记录改想法”，保留原猜想|修订可见，不把猜错当能力低|
|配对两艘相同船|暂时淡化并说明实际船始终在|从具体物品过渡到等量关系|

手机首次使用默认显示小巧伙伴，点角色可展开指导、提问、语音和暂停；学生已保存的展开/收起偏好优先。收起时表情仍响应，文字反馈留在任务区，并提供读屏提示。桌面保持展开指导。头像悬停6%放大且透明背景，遵循减少动态设置。

## 视频回片验收补充

1. C-V10不烧入“阿舟已回船/水线已对齐/你已成功”，实时状态以界面为准。
2. C-L02不把固定A/B数值写进生成视频；两次试验由学生产生。多放木块、小人上船、触底三个问题都可选，不锁死一种操作。
3. C-L03保持纸盒书箱、短铅笔与两块木楔；不替换为木宝箱或船桨；不预报300克。
4. 第一帧承接采用图，最后两秒留给界面接棒。无新口型台词时不加张嘴说话；不要让影片替学生完成配对或判断。
5. 回片后重新验证视频独立播放、图卡静帧、字幕、错误回退、返回修改、两个完整学习与短复习路线。

## 教师观察与实用建议

故事版请学生指着三张线索讲两句话，再向同桌复述“四格故事”。实验版请学生解释“A到B”与“按题目从少到多/岸上到船上/不碰底到碰底”是否同方向，避免把记入顺序当因果。书箱题可用真实纸盒、短铅笔和木楔做桌面复述。

时间按课堂情况调整，不计时、不排名。软件检查操作与答案一致性；教师仍需听学生自己的解释，不能把一次点选通过当成已经掌握。研究与推导边界见[本轮研究](23-learning-interaction-research-v13.md)。旧v1.2进度无损继续原门槛，新开始完整学习启用新步骤。
