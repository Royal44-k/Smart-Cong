# 课堂交付版 v1.7 验收

2026-10-12。在v1.6基础上新增学生控制的作品展示，继续保留连线、拖曳、拼图、图上留线、实验修理、前后回看与可选重量尺。实际视频仍由用户通过外部工具制作。

## 本轮完成

- 故事版：成果页新增“我来讲故事”，四页采用画面、短问题、自己写的话、参考讲法和同桌追问分层呈现，学生决定翻页和提示。
- 实验版：成果页新增“展示我的研究”，从自己的问题和最初猜想开始，对照实际A/B快照，回看首次与当前称象结局，再说明书箱任务。
- 学生表达：空缺留空，错误、暂定结果与原选择保留；系统不把参考冒充原话。原报告和打印也改为显示实际书箱数值及所选理由。
- 体验：键盘/触摸可完成；44像素控件、窄屏适配、长内容独立滚动，固定返回/翻页；当前页悬停保持高亮。
- 伙伴：打开展示暂停媒体和朗读、取消在途请求；迟到回答不抢话，翻页不发模型请求；退出恢复原伙伴显示与偏好，不自动续播。
- 生产：C-V11、C-L03后接新作品展示。17场景图、2透明伙伴表情组、物品图集、19镜/38句/19音轨/字幕沿用。新增[展示场记](../media/showcase-scenes.json)与[课堂制作稿](37-showcase-production-v17.md)。

独立只读审查运行36项相关测试及68个内存条件/旧进度用例，未发现可确认待修问题；审查未操作浏览器，视觉和真实交互由上述验收完成。

## 交付与限制

新版本在原服务4184运行，旧成果进入reflect后即可看到展示入口，无需重开。v1.6存档结构和存储key不变；原始图注、反思、首次结局、书箱答案、声音偏好保留。称象练习路线不增加新门槛。

交付清单由白名单生成，检查本地链接并逐文件记录SHA256；ZIP创建后回读每条内容核对长度和哈希。旧ZIP保留。实际视频生成、外部付费模型的在线质量和真实学生课堂效果不在本轮已验证范围；接口及完整视频前期继续提供。
