# v1.7 把作品讲给同学听：课堂与制作执行稿

2026-10-12。范围：完整故事和完整实验的成果页。沿用既有图像、原声、故事分支、模型接口与学生存档；本轮新增学生控制的展示视图，实际视频仍由用户外部制作。

## 为什么这样改

v1.6作品页适合填写、回看和打印，但任务信息、写作框和成果混在一起，不便用于面对同桌讲述。故事版需支持按顺序组织语言；实验版需支持指向真实证据、解释修改。采用“原作品可编辑 + 可选只读展示”的方案，避免再给学生增加一道必做任务。

[研究记录](36-presentation-retrieval-research-v17.md)核读小学引导检索原研究、IES解释建议、NGSS科学表达进阶和W3C展开模式。本产品的具体设计是对来源的应用推论。展示不录音、不测发言时长、不计分，也不根据翻页或查看提示判断掌握。

## 故事：四幅画，由我来讲

入口位于“我的《曹冲称象》小书”标题下。四页复用已采用静帧；点击“我来讲故事”后呈现大画面、短问题和独立展开项。自己的话、参考讲法、同桌追问都默认收起，学生随时能看。自己没写时显示留白说明，不用参考代填。

|页|画面及逻辑|学生可以怎样讲|参考/追问|
|---|---|---|---|
|1 先|大象上船；阿舟在船上，照护者在岸|遇到什么难题，谁先上船，要等到什么时候|船还在晃，能马上画记号吗？|
|2 再|船身、水面、记号近景|记号在哪里，记住了什么|为什么不画在浪花上？|
|3 然后|象上岸后的既有场景图|怎样用石头换下象，还要看看谁|水线对上，阿舟位置不同，能直接比吗？|
|4 最后|分批称量与记录场景|每份怎样称、怎样记，最后怎样合计|漏记一堆会怎样？|

图为故事场景，不冒充学生操作后的动态截图；实时称象图仍用于原任务。原图注在编辑区、打印和导出中保持原样。展示中不自动播放后续收到的视频；选择静帧是为了把讲述时间交给学生。

## 实验：拿着证据，开一场小研究会

入口位于“我的小船实验报告”标题下。四页标题、证据布局和引导与故事不同，保留“猜想—记录—解释”的联系。

|页|读取什么|如何呈现|不推断什么|
|---|---|---|---|
|提出问题|选题、最初猜想|模型桌采用图 + 两条原选择 + 邀请解释|不把后来正确结论写回最初猜想|
|用记录说话|A/B已存快照、观察选择、修订选择、第一条反思|A/B船图并列；每栏保留木块、小人、船底条件；文字标“我选的…”|不拿当前桌面填缺失记录；不把选择句称为学生自写原话|
|回到大船|当前cargo/counts/crew、原填质量、首次/当前结局、issues、第二条反思|原实时船图、实际装载与账页分别显示、待查内容可展开|不把暂缓、错误或条件缺口展示成已确认|
|换个问题|书箱原填数值、原选理由、已用试分、第三条反思|题目实物与已有回答分开；可选追问工具两次都留船的情况|不把自动余量或看过参考当作独立掌握|

空白保持空白，错误保留原值。研究展示和原报告都要使用真实的书箱回答，不再固定写“我说明了工具的变化”。

## 课堂使用与观察

建议故事分享约2—4分钟，实验分享约3—5分钟；这是安排参考，没有系统计时。可先同桌轮讲，再由愿意的学生全班展示。学生可以指图、看自己写的话，也可以看参考重新组织语言；求助不扣分。

教师听三件事：故事能否连起先后和关键条件；实验能否指出具体A/B差异；遇到不一致能否解释还要查什么。教师可只追问一处，不把四页变成四道口试。必要时回原作品补写；软件不从浏览行为给能力结论。

## 操作和版式

- 顶栏保留返回；底栏保留上一页、下一页和4个页码。左右方向键可翻页，首尾不会循环；Escape可退出。
- 文字提示使用原生details/summary，键盘Enter/Space可展开。每次翻页重新收起提示，不改学生文字。
- 1440宽桌面使用图文并排；窄屏上下排列。A/B两栏同屏对比，长反思在内容区滚动，固定导航不覆盖正文。
- 按钮和summary至少44像素；当前页兼有文字页码及选中状态；降低动态偏好沿用全局设置。
- 原透明曹冲/小象保留。在展示期间暂时隐去，暂停媒体与朗读、取消未结束的模型请求；退出恢复显示但不自动开口或续播，不改声音偏好。
- 页码和显隐状态仅属于本次展示，存档结构仍为root v3、learning revision6，存储key不变。

## 视频接棒与资产锁定

[场记数据](../media/showcase-scenes.json)对应C-V11和C-L03的界面接棒。原19镜、38句、17场景、19音轨保持不变；本轮不新增视频任务。

C-V11按原剧情结束，由学生完成排序、进入小书，再自行启动放映。不要在电影里拍出固定的“学生已经讲明白”反应。C-L03按原书箱任务接出，学生完成配对和手算进入报告，再展示实际证据。原模型数字、学生反思和动态结局由界面显示，不烧录进视频。
