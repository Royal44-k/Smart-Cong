# v1.3 学生说理与观察升级计划

日期：2026-10-12。范围：在现有两条完整学习路径上升级，保留称象练习、结局分支、存档、头像透明悬停、原有影视资源与视频接入口。

## 走查依据
本轮已截图 story / pond / lab / home。IAB 控制工具连续两次初始化失败，改用独立 Playwright Edge 上下文捕获真实本地页面，不改用户学习记录。
- 故事开场用系统表情代替物品，与既有美术不一致。
- 故事报告主要依靠读长句二选一，缺少学生选取证据的过程。
- 实验 A/B 图与表格重复占较大篇幅，却没检查学生看见的实际变化。
- 书箱题从文字直接跳到数字，缺少具体物品到算式的过渡。

## 设计与实现
1. 故事报告：三张图证据（船、水线、阿舟）＋形状干扰项，逐一观察，组合理由；保留错误报告与修改结局。
2. 实验观察：A/B 同机位可推拉比较；由学生选择真实方向，再对照最初猜想。按题意归一化解释，不能把倒序记录当成猜错。
3. 迁移题：配对两次都在的小船，再辨认砝码替代的物品，最后学生自己填数。配对可撤回。
4. 图片：内置 imagegen 生成统一无字物品图集，项目内保存、记录提示词和验收。不用图片承载必须可读的题目。
5. 旧学习存档迁移保持原来进度，新开始的完整学习启用新检查；实验改记 A/B 会清空依赖旧记录的解释。
6. 伙伴反馈只夸已完成的具体观察；帮助、无鼠标操作、触屏和减少动态保持可用。

## 布局目标
沿用故事暖纸绿、实验淡蓝与深蓝按钮。故事保留左电影画面、右任务；实验工作区保留船与控制器，下方紧凑比较、观察、猜想卡。图证据横排，小屏单列；字体至少16px，触控目标至少44px。新交互不自动朗读、不计时、不排名。

## 验收
先写行为测试并看到失败；实现后运行新旧单元与浏览器验收。截图同视口对照现有设计基线，标明有意的新增区，不将新功能误当视觉漂移。补交互生产表、镜头入口出口、图片清单、反馈台词和教师使用说明。生成新的 v1.3 交付包并逐文件校验，保留旧包。
