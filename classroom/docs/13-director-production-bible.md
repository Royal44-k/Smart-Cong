# 《曹冲称象：一线之差》导演剧本与视频生产手册

课堂交付版1.8 · 2026-10-12。17张采用图、19个镜头任务、38句对白、19段朗读及对应字幕。视频由外部工具制作；剧本、分镜、互动接点、采用图和声音已按两条路线组织。

## 两条叙事主线

**故事版：今天，我是曹冲的小帮手。** 大象来到码头，小秤承不住它。孩子先看物品、玩小船，再为大象画下水线。象离船后，阿舟取秤上岸。多出来的一小堆石头使事情出现转折。孩子找人、调石头、替称重条找朋友，选择解释、回查或暂缓。最后把自己经历的过程排成四格小书，讲给新伙伴。情绪从好奇、试探、惊喜到发现变化，再到“我能讲明白”。

**实验版：今天，我来研究一个问题。** 学生从木块数量、小人位置、船底触底中自选一项，先提出猜想、安排单项变化的A/B试验。用实际记录审视猜想后，带着条件意识回到称象现场。水线相同但人员改变，学生通过恢复条件或计算差额做出解释；还可保留暂定结论。新的书箱问题把变化从“人”换成“工具”，防止只记住2700这个数。最后形成自己的实验报告。情绪从自主提问、验证、发现反例到修订与迁移。

## 角色与场景锁定

曹冲：青灰蓝交领衣、米白袖口、棕腰带、小发髻，与学生平等对话。老匠人：灰白长须、褐袍，模型桌左侧；曹冲在右。阿舟：深灰蓝短袍、浅腰带，无管事式头巾；船上唯一船工。照护者：米色长袍、棕腰带，在岸照顾象。帮工和管事是独立配角，分别以结局图锁定，不能替换阿舟。角色参考：CC-CHARACTERS。

晨间码头：右岸、船首向右、船尾在左；上象到下象沿用同船同轴线。模型桌延续老匠人左、曹冲右。E3可转夕阳表示暂歇，回查通过操作台继续，不硬剪成同一瞬间。现代课堂以水面匹配转场；故事桌面四张卡，实验书箱桌面无排序卡。

## 数值与物件连续性

历史场景的实验数据用于本课推理：船及固定物1000 kg、阿舟60 kg、象2700 kg；留线总质量3760 kg。阿舟回船时四堆石头450+600+750+900=2700；阿舟在岸时加60的一小堆才同线，石头总计2760，需要说明并减去人员差额。故事版隐藏大数，以五种图案对应物件，最终要求恢复阿舟并去掉小堆。实验版允许恢复人员或计算差额。

桌面实验：木块每块10克，小人20克；船底触底时有盆底支撑，不能把浅水船位简单当成浮力比较。书箱任务：同船、同水、平稳、自由漂浮、同线；第一次含20克工具，第二次320克砝码不含工具，书箱300克。工具在采用图中为短铅笔和两块小木楔，其合计质量由界面给定。

3. 人声先清楚，再添加低音量水声/室内声。现有19段朗读可直接试听，影视配音可按38句文本重录。镜头目标长度由真实音轨长度计算，视频剪辑完成后重新对齐VTT。
4. 画面不烧入正确答案、变化的记录和船上人员状态；操作期间以实时船图为准。E4不能固定责问某一错误。学生未通过不播放成功反应。
5. 按回片表逐项核对人物、道具、首末帧、轴线、光向、对白、字幕、条件与后继。录入src/media.mjs对应video路径；保持poster和字幕。仅把视频文件放进目录不会自动改变路线。
6. 声音不自动播放；返回同页操作保留音轨播放位置，跨页停止旧声。视频失效回退到采用图，仍可继续互动。回片完成后重跑完整学习、纠错与媒体回退测试。
