# 学习伙伴模型接口 · 管理员配置

小曹冲与小象共享同一服务端适配器，根据当前版本使用不同称呼和提示。未配置时，全部互动、结尾和本地指导照常可用。密钥不进入页面、学习记录或交付清单。

## 配置

需要Node.js 24或以上。在项目根目录复制 `.env.example` 为 `.env`，仅在自己的电脑填写密钥，然后双击“启动体验.cmd”。如果服务已经运行，关闭该项目原服务后重新启动。

```dotenv
CAOCHONG_AI_API_KEY=在这里填自己的服务端密钥
CAOCHONG_AI_BASE_URL=https://api.deepseek.com
CAOCHONG_AI_MODEL=deepseek-flash
```

也可在PowerShell设置同名环境变量，再运行 `node server.mjs`。直接使用配置文件时运行 `node --env-file-if-exists=.env server.mjs`。不要把 `.env` 发给学生或放入压缩包。

核查日期2026-10-10：DeepSeek官方当前推荐 `deepseek-flash`；`deepseek-v4-flash` 旧别名仍接受，当前临时转向新模型。已有该名称可填入模型配置项。模型实际路由以[官方模型页](https://api-docs.deepseek.com/quick_start/pricing/)和[更新日志](https://api-docs.deepseek.com/updates/)为准。

基础地址支持HTTPS的OpenAI兼容Chat Completions服务；适配器包含DeepSeek的 `thinking` 扩展和JSON输出参数，其他供应商需确认兼容后调整。项目不会自动替你创建账户、购买额度或测试收费请求。

## 浏览器与服务端约定

|接口|作用|
|---|---|
|GET /api/companion/status|仅返回available布尔值；不返回密钥|
|POST /api/companion|接收当前短问题及课堂状态，返回reply和source|

请求问题1至180字符、整包不超过4096字节；当前版本、阶段、路线、船工状态、同线状态和称记数量按白名单提取。忽略其他字段，不附带整份操作日志、反思或浏览器存档。学习页面说明只写学习问题，不提供姓名和学校。

服务端只接受本地同源JSON请求；不开放跨域调用。模型端默认8秒超时，最多3个同时请求、每分钟20次外部请求。超限、未配置、断网、截断、空答、格式不正确或不适合直接展示的输出都回到本地提示。不把上游错误或密钥写入学生页面。

输出采用JSON reply字段，限制200字符；提示词要求至多80汉字。对数字答案、标签、链接和部分越权成功措辞做过滤；这不等同于全面语义审核。模型文字不能调用关卡函数、给分、解锁或修改进度。学生做了新的操作、切换版本或阶段时取消旧请求，迟到回答不覆盖新任务。

## 使用与验收

学生主动点“问问伙伴”，写问题，再点“请伙伴想一想”才发起一次请求。常规成功表情与夸奖均来自本地实际状态，不消耗模型调用。未配置时显示“先从这条线索想一想”，提供当前任务提示，不声称已经获得模型答复。

自动化测试用模拟服务核对正常JSON、错误内容、超时、来源、请求大小和状态隔离。当前没有用户密钥，因此没有进行真实账户的收费联调。正式填入密钥后，管理员应分别测试故事提示、实验提示、错误问题、换关和断网；不要把HTTP成功等同于儿童用语质量合格。
