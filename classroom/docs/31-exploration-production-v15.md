# v1.5 学生操作与制作衔接
## 本轮设计
保留故事版河岸绿、宣纸色与宋体标题；实验版沿用水蓝、深蓝与清晰黑体。色值：河岸绿 #285b55，纸白 #f8fbf5，水蓝 #eaf3f7，深蓝 #315d7e，水线金 #ba923c。已有教学图和影视场景图保持原用途。
故事核心：图上点选或划线 → 留下位置 → 看具体解释 → 请象上岸。点选、划线、键盘按钮具有相同结果；不计时，不给笔迹打分，不增加通关条件。
实验核心：左侧摆船与A/B记录卡，右侧比较与解释。窄屏顺序阅读，三步导航可直接定位。照A/B摆回只改变当前小船，不能改写已保存记录、猜想、观察和结论。
学生未写的反思在打印时留白，问题另列，不替学生写第一人称答案。

## 操作验收
- 图上船身、浪花、岸柱均可选择；错误位置给出原因，可重新选。
- 划线中取消、离开页面或多指干扰不意外提交。
- 图上操作和下方按钮等效；触控目标不少于44像素，划动不以精细运动能力计分。
- A/B恢复不隐式写回；学生点击“记入”才替换记录，相关推理按原规则重新检查。
- 步骤状态只反映实际记录和解释，不能由导航点击获得完成标记。
- 新布局兼容320/390/768/1440像素、键盘、减少动态效果、旧存档；数字伙伴悬浮背景仍透明。

## 实际接入状态
本轮已实现上述操作与视觉布局。精确水线高度仍由系统沿平静水面呈现；学生选择的是记号依附的物体，未另加高低位置题。图上划线的起笔区域代表所选物体，不按笔迹评分；松开在画布之外、Esc、触控取消、第二指落在任意区域或失焦均取消本次操作，不改变学习结果。
输入共用原有 line 状态与继续门槛，保存结构保持 learning.revision=5，旧存档无需增加字段。A/B“照着摆回”只恢复 weight/crew/free 到桌面，修改正式记录仍会撤销过期观察、猜想对照与结论。

C-V05 与 C-L02 的新版接出说明已写入[镜头数据](../media/shots.json)、[视频任务表](../media/video-task-list.csv)、[导演手册](13-director-production-bible.md)及[本轮交互场记](../media/exploration-scenes.json)。保持原对白与音轨：C-L02建议先记A，但学生先记B同样可行。视频素材数量、角色、轴线与道具不变。
数字伙伴仍位于界面层，透明图像与轻微悬停放大保留。键盘焦点避开步骤栏、展开消息、头像和设置区；手机触控时不自动滚动焦点目标，防止点下时目标跳走。
打印的三个反思区按对应问题另列，未写内容留可填写空白，不代替学生写第一人称回答。
