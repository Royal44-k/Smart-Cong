# v1.8 同桌出题、条件变式与解释反馈研究

研究日期：2026-10-12。研究方法：核读五份官方/原始发布资料，并与v1.6、v1.7已有研究和本轮已确定方向对照。本轮未试玩外部游戏、未开展儿童试验、未检验应用实现。下文“可测边界”均是待实施的验收要求。

适用范围：成果页后的可选互动。故事版面向二至三年级，采用“藏起一幅图”；实验版面向四至六年级，采用同船称书箱的自编变式。支持同桌轮流，也支持自己玩；不增加原通关条件。新增价值是让学生决定给别人什么条件，并在条件改变后重新解释，而非增加一轮重复选择题。

以下五条是结合这些来源提出的**项目设计推论**，不是来源的逐字规范。界面文案、题型组合、状态设计与数值推导均为本项目方案。

## 1. 给出题人一个真正影响题目的选择

依据：R1、R3。出题权应改变同伴需要发现的关系，而不仅是换一个颜色或随机题号。

故事的出题人从已有四页中选一幅盖住，交棒后由答题人补回画面。实验的出题人决定工具在哪次船上，再选择砝码和工具重量。已确定的三组选择为砝码220/320/420克、工具20/40/60克、工具只第一次/两次都有/只第二次，共27种独立题设。

“只换数字”主要增加算术练习；“改变工具在哪一次”才会改变关系。入口不宜直接以“减法题、等式题、加法题”命名，避免把本应观察的结论预告给答题人。画面分别标“第一次”“第二次”，工具身份与重量一致。

更有区分度的后续玩法可在答完后邀请：“让答案变了，只改一个条件，你会改哪里？”或“换一题，让工具还在，却不用减它。”它们是可选的下一题目标，不应在当前题还未作答时泄露规则，也无需本轮一次实现。

**适龄文案：**“这回你来出题。”“把工具安排好，请同桌来发现。”“每换一题，就换一箱书。”

**可测边界：** 每个选择都能在交棒前预览；交棒冻结题设，答题端不能悄悄修改。出题人选完条件不等于已经答对；点击“题出好了”不得生成掌握标签。若采用27种组合，均须有明确、正数且唯一的书箱重量。

## 2. 藏图的两步分别看“发生了什么”和“为什么需要它”

依据：R4、R5。补图可能仅反映顺序记忆或视觉辨认；说明作用才提供进一步观察理解的机会。二者应分开显示和记录。

推荐流程为：出题 → 交棒 → 补图 → 说明作用 → 回看/换人。答题人先看其余三幅，从图卡中补回缺失画面；成功进入作用问题后，再说或选择这一步怎样帮助称象。若把“留下同一水线供比较”之类理由提前显示，会直接暗示缺的是画记号图。

作用问题须对准关键条件：例如“这个记号帮我们记住什么？”“石头换上船后，还要看哪里？”不要求复述唯一标准句，可先指图、口述，再看短句参考。软件选择题通过只能表示与该题规则相符，不能自动判定口述完整正确。

掀纸帘应是可用帮助。掀开后仍可继续补图、解释；这一轮标“看过原图”，收起纸帘不能把标记洗掉。自己玩时曾见过自己选择的图，也不应称为从未见题的独立测验。

**适龄文案：**“咦，少了一幅！把它请回来。”“这一步帮了什么忙？”“想看看原图？掀开纸帘也可以。”“图补好了，再讲一句它的用处。”

**可测边界：** 补图阶段不显示答案式理由；补错保留所选图并允许改；解释问题跟随实际被藏页，不沿用上一题。求助后继续作答，状态如实注明帮助；提示记录不加减分。不能用“已讲给同桌听”的按钮声称系统听懂或验证了语音。

## 3. 书箱变式必须由同一条重量关系推出

这一节是本项目题设下的数学核验，不是借用教育来源来证明物理定律。

每道题固定为同一艘船、同一水体，船平稳、自由漂浮且两次对齐同一水线；船与其它未提及载荷不变。第一次放书箱，第二次放已知砝码。工具是否在两次船上由出题人设置。图卡表达两次已满足条件的记录，不能假装是实时漂浮实验。

设书箱为X克，砝码W克，工具T克，第一次/第二次是否有工具分别记为a、b（有为1，无为0）：

X + a × T = W + b × T，因此 X = W + (b − a) × T。

|工具位置|对齐水线时的载荷关系|书箱计算|W=320、T=20示例|儿童可用解释|
|---|---|---|---|---|
|只在第一次|书箱＋工具＝砝码|W－T|300克|“砝码这一份里，还顶着工具的重量。”|
|两次都在|书箱＋工具＝砝码＋工具|W|320克|“两边都有同样的工具，这一份相同。”|
|只在第二次|书箱＝砝码＋工具|W＋T|340克|“第二次除了砝码，还多了工具那一份。”|

27种组合中最小书箱重量为220－60＝160克，最大为420＋60＝480克；输入、反馈与图示范围须覆盖这些结果。这只验证数学范围，不代表已测试程序。

**关键叙事边界：** 固定W、T而换工具位置时，上表是三道不同的书箱题。不能让同一箱书从300克“变成”340克，还说只是移动了工具。已确定采用题目图卡，并明确“每换一题，就换一箱书”，可避免这一误导。若未来改成同箱实物模拟，就必须使砝码量、水线等状态遵从载荷变化重新计算。

**可测边界：** 修改条件必须退回出题、清空当前解答及当前成功反馈；不能继续展示旧的“算对了”。可保留最近一次实际作答记录，但要绑定当时题设，避免与新题混排。未来若增加换船、触底、改变水体等选项，应允许判断“还不能这样比较”，不能继续套三种算式。

## 4. 交棒要改变任务，反馈要回到可检查的证据

依据：R2、R3，解释反馈的时间与内容参考R5。双人模式的区别应是两个人各做一件事：甲安排条件，乙读题解释；下一轮交换。一个人玩保留同样的操作机会，但明确是自己出的题。

交棒页可以只留“轮到你啦，先看看两次船上有什么”，按“我来解题”进入。它是课堂轮流的提示，不是能防止偷看的安全机制。出题人的预览或答案不能留在解题画面上。角色用“出题人/解题人”即可，无需填写真实姓名。

错误反馈最好显示本次实际关系，而不是仅“再试一次”。例如只第一次有工具、学生答320克，可说：“按你的答案，第一次是320＋20克，第二次是320克。两次一样重吗？”两次都有工具时若仍减20，则提示比较两边是否都已有工具。遇到其它错误数值，给出真实回代结果，不能据此断言儿童“粗心”或“不懂加法”。

每次操作立即确认发生的事，例如图卡已选、工具已换位置；完整推理在检查或主动求助时展示。学生输入时不逐字播报“错了”，也不自动替换为正确答案。检查后提供当前题的具体解释，并允许修订。

**适龄文案：**“轮到同桌来试啦。”“先别急着算，找找工具在哪两次出现。”“把你的答案放回两幅图，两边一样重吗？”“这题说清楚啦，换你来出一题。”

**可测边界：** 交棒后图卡、题干、算式、反馈引用同一份题设；返回改题时旧答案明确失效。首答、改答和看过提示是不同事实，不被最终正确状态覆盖。误输入、空输入与概念回答分别处理。不得将同桌按“听懂了”当成已测得的学习成效。

## 5. 用短句和少量观察项检验设计，不用完成次数代替理解

依据：R1、R4、R5。保持一屏一个主问题，图上用对象名、顺序与单位表达条件。用“在哪次船上”“这份重量是谁的”替代“控制变量”“等量代换”等首次出现的抽象词。若需术语，在儿童先说出关系后连接，不让术语成为参与门槛。

本轮研发验收可以证明三件事：学生真的能改题并交棒；场景与计算一致；回答、提示与修订被如实呈现。它不能证明学习提高。建议试用时只观察以下四项，同时注明年级、任务和帮助情况：

|观察项|可记录的证据|不能据此推出|
|---|---|---|
|辨认故事作用|补图后指出该步保留或改变的条件，可口述或指图|补对图片就理解完整称象原理|
|读条件再计算|能说明本题工具在哪一次，算式对应哪一份|填对一个数就能迁移到任何称重情境|
|处理变式|面对工具位置改变的新题，重新解释而非照抄上一题|连做三题就形成长期稳定能力|
|交流与修订|同伴提出一处疑问，出题人补充说明；答题人根据两幅图改答|轮流点击本身等于合作学习成功|

教师可追问：“刚才那题要减，这题为什么不用？”记录儿童原话与是否看过解释。比较时至少区分“改数字、关系不变”和“工具位置改变、关系改变”。可在后续活动再给一道未见过的同构题观察保持情况；这属于建议的学习验证，当前未执行。

## 本轮实现优先级与边界

优先完成故事“补图后再说作用”、实验27种题设的统一计算与交棒冻结、求助和最近实际作答的如实记录。以往选择、拖曳、连线、拼图、A/B探究、修理、重量尺和展示继续服务原目标，新游戏作为成果页可选入口。

更有价值的下一步是让答题人对同伴的题进行一次有目的改编，例如“只改一个条件，让书箱更重”，并解释为何变了；这需要先检验儿童是否能清楚区分“换了一题/换了一箱书”和“同一实物正在变化”。暂不为新颖而叠加更多操作方式。

五份资料共同提供的是可追溯的设计参照：让学生发起、观察条件、交换尝试、解释并修订。它们未验证本应用、该题型、此年龄组合或中文文案的效果。软件验收与儿童学习研究必须分别报告；本文件不声称v1.8已提高成绩、注意力、推理能力或迁移能力。
