# 课堂交付版 v1.8 验收

2026-10-12。在v1.7作品展示基础上新增“我出题，你来解”，保持两版主线、四种结尾与全部既有玩法。视频仍由用户通过外部工具制作。

## 本轮完成

- 故事：学生选择藏起四图之一，交棒给同桌；先补图，再说明作用。可掀帘求助，先后与用途分别核对，错误保留并允许修改。
- 实验：220/320/420克砝码、20/40/60克工具及三种工具位置，共27种独立书箱题。单题固定同船同水、平稳自由漂浮同线；每换一题换一箱书。先比较、再计算，核对后按实际输入回代两次装载。
- 角色与记录：出题、交棒、解题、交换分开；同桌轮流或独自参与。两版分别保存当前进度与最近六次实际核对，不记姓名、不替学生说话、不加新门槛。
- 体验：改题撤销旧成功和试算；相同题下一轮独立留档，本轮同值重复点击不堆叠。手机试算两行对齐，单位不单独折行。输入保留焦点，全角数字与输入法结束正常处理。
- 伙伴：进入时暂停原媒体与朗读、取消在途模型请求；工坊采用原透明角色反馈，返回恢复显示与偏好，不自动续播。
- 生产：C-V11/C-L03之后接可选新工坊；原17张场景、2组透明伙伴、6件物品图、19镜/38句/19音轨/字幕保持一致。新增[场记](../media/peer-challenge-scenes.json)、[执行稿](40-peer-challenge-production-v18.md)及[五份官方资料研究](39-peer-challenge-research-v18.md)。

## 存档与交付

根version3及存储key保持不变，learning revision6自动升至7并补空工坊。此前已完成完整学习的成果页可直接进入，无需重开。新玩法可随时退出；浏览器刷新继续当前题与阶段。交棒是课堂轮流提示，不是防偷看的权限机制。

交付采用文件白名单、本地链接检查、逐文件SHA256清单及ZIP回读校验；旧版本ZIP保留。交付范围为可运行课堂、图片声音、教学资料和完整视频前期，本轮没有生成实际影片。

功能、规则和视觉验收通过不代表已经证明课堂学习效果。本轮未开展儿童试用；教师可按研究文件的观察项收集真实表达和迁移表现。未配置外部模型时仍有完整本地指导，接口保留；外部模型在线答复质量不在本轮验证范围。
