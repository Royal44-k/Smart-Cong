# 影音资源规范 · 课堂1.2

生产唯一入口为[导演手册](13-director-production-bible.md)、[镜头数据](../media/shots.json)和[任务CSV](../media/video-task-list.csv)。

每镜包含：ID、节点、目标时长、参考图、进入/结束画面、镜头、节拍、对白、声音、互动出口、状态门槛、后继、场记、提示词与输出名。每镜使用一个采用图作为图生视频输入，导演手册规定运动和末帧停留。双帧工具可按相同参考构图制作尾帧，不改变状态。

图片：采用17张PNG，尺寸和SHA-256见[资源清单](../media/catalog.json)。程序绘制水线、配重、人物配置与记录，准确数字由界面显示。

声音：19段WAV，PCM 22050 Hz、16位、单声道；38句独立源文件保留在media/audio/lines。曹冲与新伙伴使用Microsoft Yaoyao，成年人物使用Microsoft Kangkang，本地System.Speech朗读，语速-1。学生端手动播放，跨场景停止，同场景操作保留播放位置。制作可直接使用朗读，或按同文另配影视声音。

字幕：19份VTT，按本次朗读实际长度分句对齐。合并音轨有0.2秒起始、约0.45秒句间、0.3秒结束静音；每段均有足够画面留白。若另录对白或改变剪辑，须同步改时码。

视频：建议16:9、1920×1080、H.264 MP4、全片统一24或25 fps、AAC声轨。命名沿用shots.json的expectedVideo，当前videoReceived均为false。已有音轨audioReceived均为true，其性质为课堂对白朗读。

静帧、对白文字、可选音轨和交互可独立使用。视频不可用时回退静帧，图片不可用时保留场景文字，音轨不可用时保留对白。程序不会因媒体失败封锁教学流程。


## 1.2互动与学习伙伴补充

连线、拖曳、四格换位和找变化小游戏，以及小曹冲/小象的表情、台词、触发与视频衔接，统一按[互动与伙伴制作规范](20-interaction-companion-production.md)执行。已有镜头首尾保持一致，实时状态和反馈属于界面层。
