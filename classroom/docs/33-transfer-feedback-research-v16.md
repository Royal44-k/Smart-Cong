# v1.6 并列比较、重量分解与迁移反馈研究

研究日期：2026-10-12。适用范围：《曹冲称象：一线之差》故事版（二至三年级）的 load 阶段，以及实验版（四至六年级）的 source 书箱迁移题。本轮只研究这两处既有任务的表征与反馈，不增加强制关卡。文中的设计均是待验证的项目推论，不是已实施状态或学习效果报告。

## 研究结论与项目问题

建议把故事中的文字“看变化”改为可指认的两幅同构场景，把实验中的“320 克”改为能分出工具份额的整体，并在原处连接算式。创意来自学生能改变、比较和解释的关系；不依赖多一轮答题或更多奖励。

现有故事动作已区分船、工具与阿舟，也允许阿舟回船；书箱题已要求配对同一艘船、判断砝码替代“书箱和工具”，最后填写重量。应保留这些判断的意义，将新的图上操作接入它们，而不是复制成另一套必做流程。项目事实已核对 src/learning-actions.mjs 与 src/reasoning-state.mjs，制作背景参考 [v1.5制作衔接](31-exploration-production-v15.md)。

## 六条可落地原则

### 1. 两幅图必须真的能逐项对照

依据：R2区分同时展示和实际比较；R1要求突出对应关系。

故事 load 内并列“留记号时”和“这一次”。用同样的船形、视角、岸边参照物与物品身份，固定第一次记录，实时显示第二次状态。首次问题可写：“大象换成石头了。再找找，谁的位置也变了？”允许点两幅图中的阿舟，均指向同一项比较判断；船与原有船桨也可点选，但反馈应说它们是否改变。

不要把衣服颜色、构图尺度、道具数量或镜头方向随意换掉，再要求儿童猜唯一正确差异。阿舟上岸是实际差异，象换成石头也是实际差异；问题应明确“除了象换成石头”，避免把正确观察判错。

**可测边界：** 初始图显示阿舟由船到岸；请他回船后，第二幅图、说明和操作入口同步更新为“两次都在船上”。第一次图不得跟随当前操作改变。误点船时不得解锁阿舟变化，也不记录成操作能力不足。

### 2. 发现差异后，给学生观察后果的机会

依据：R4的动作—反馈关系；R2的比较需要指向关系。

学生发现阿舟在岸上后，可在原处选择请他回船，再看水线怎样变化。把“指出位置不同”和“恢复可比条件”区分开：前者是观察证据，后者改变当前载荷。不要点中阿舟就自动把他搬回、自动调整石头或跳往下一步。

二至三年级可用一句关系提示：“他回船后，船上又多了一份重量。水线还对着记号吗？”保留原来的换载判断，让学生自行调整。若当前已在船上，就准确说明现状，不再机械提示“找到了，他在岸上”。

**可测边界：** 相同石头数量下，阿舟上下船必须触发与既有物理模型一致的水线变化；找到差异不等于水线已相合。相合也不应越过船平稳、自由漂浮等既有条件。

### 3. 把320克标成一个整体，再分出工具那一份

依据：R1支持具体与抽象的显式联系；R4支持能揭示关系的操作表征。

书箱题保留两次同船、同水线的原题设。在两条记录下方清楚写出“砝码共320克，替代书箱和工具”。学生可在同一条重量带或两个份额区中，把20克分给工具，余量属于书箱。标签必须写明对象、数字与克，不只依靠颜色。

推荐一次有意义的分配动作即可表达“整体减去已知部分”，无需让学生来回搬16个小块或逐个凑数。点击、按钮或原有输入均可驱动同一个重量关系。界面可以计算剩余量，但这只算辅助呈现，不能同时记为学生独立算对。

重量分配操作是在账面上分解320克，不是改变原实验船上的装载。若表现成从船上拿走真实工具，就必须更新相应水线，不能继续展示原来的同水线状态。画面应明确区分实验记录和计算区域。

**可测边界：** 320克整体不因分配被复制或增大。若设计为始终分完，两部分之和必须始终为320；若允许暂未分完，必须显式显示未分配部分，三者之和为320。工具0、20、40、320克以及撤回都不能产生负数、超额或第二份320克。

### 4. 算式要解释画面中的对象，不只显示答案

依据：R1要求指出表征间的对应关系。

书箱题的完整关系为：

- 第一次：同一艘船＋书箱＋20克工具。
- 第二次：同一艘船＋320克砝码。
- 在题设的同水线、可比条件下，去掉两边相同的船：书箱＋20克＝320克。
- 求书箱本身：书箱＝320克－20克＝300克。

用对象标签将“工具20克”与算式中的20相连，将总重量带与320相连。可在学生检查后呈现完整等式，或提供可展开的解释；无需让已经会算的学生再点击完全部动画才能提交。原有输入仍允许独立完成。

**可测边界：** 不把“同一艘船”简写成任何两艘船均可抵消；不把“同水线”推广为任意船、任意水体和有外部支撑时都等重。若展示正确剩余300克后用户再填300，记录只能说明本次答案正确，不能声称独立计算成功。

### 5. 错误提示应指向下一次检查，而非替学生宣布想法

依据：R3关于具体缺口与使用反馈的机会；R4关于可理解、可再尝试的反馈。

在学生点击原有“检查”时使用有针对性的提示，保留其当前答案与分配，允许立即修改。数量拖动或输入期间只更新可观察结果，不在每一步播放错误音或打断操作。

|学生当前提交|建议反馈|反馈边界|
|---|---|---|
|选“只替代书箱”|“看看第一次，书箱旁边还有哪件东西也有重量？”|先回到记录证据，不立即代选“书箱和工具”|
|书箱填写320克|“320克里已经包含工具。你现在想求的是书箱这一份。”|指出可能遗漏的部分，不断言学生不懂减法|
|书箱填写340克|“这320克已经替代了书箱和工具。再检查一次：工具那20克是不是又加了一遍？”|这是与数值相符的检查方向，不是确定的心理诊断|
|其他有效数值但不符题设|“把你给书箱的重量和工具20克合起来，能回到320克吗？”|不编造具体错误原因；让学生用回代检验|
|空白、非数值或超出当前表示范围|“先填一个能表示这份重量的数，再检查。”|输入问题不计为概念错误，已完成的比较仍保留|
|300克且现有条件判断满足|“本题书箱是300克。它和工具20克合起来正好320克。”|仅确认本题结果，不宣布学生已掌握迁移|

**可测边界：** 连续求助不得暗中填答案或覆盖学生解释。成功状态依赖的答案或条件一旦改变，应重新检查，不能保留过期成功。用户此前独立填对，之后打开图解，不应被迫重新闯关。

### 6. 用已有反思检验能否解释结构，把迁移留给真实回答

依据：R1提醒具体任务完成不保证迁移；R3要求观察学生如何使用反馈。

复用故事小书和实验报告的已有表达入口，允许口述、指图或简短记录。故事可问：“阿舟回船以后，为什么还要再看水线？”实验可问：“如果工具两次都留在船上，320克这次只替代什么？”后一变式的目标是辨认两边共同部分；在其余题设不变的假设下，工具与船一样属于共同部分，书箱对应320克。

变式是教师试用或可选讨论，不新增完成门槛。为了看迁移，先不展示相应解法，让学生说明，再提供反馈；不要把在原题图解旁抄出的句子当成独立解释。

**可测边界：** 教师分别记录“能指出差异”“能解释总量与部分”“能在改变工具位置后重新判断”，并注明是否使用提示。软件最多如实报告选择、答案、修订和原话，不能只按字数、关键词、操作次数或通关判定掌握。

## 最容易误教的五处

1. **把视觉相同当成条件相同。** 两张不同船的插图碰巧一样高，不能代表同船比较；同一艘船也不能在触底或倾斜状态下仅靠局部水线得出结论。
2. **把“找阿舟”做成猜作者想要的按钮。** 学生指出象换成石头本身是正确观察，须用任务措辞缩小观察目标，不能否定它。
3. **把分重量画成移实物。** 计算区域拿出20克不应悄悄改变实验记录；真实移走工具却冻结水线，会教出错误因果关系。
4. **把320克当书箱初始重量。** 始终标成替代总重量，并呈现其与书箱、工具的对应；否则减20会变成无理由的口诀。
5. **把系统帮算或系统给提示后的正确答案称为掌握。** 本题通过只说明当前提交满足规则，长期保持与新情境迁移仍需独立观察。

## 实施验收与证据边界

研发验收应检查：两幅图的身份一致性与状态更新；船、人、工具选择是否复用既有判断；重量守恒、单位、撤回与修改；每类错误是否保留原输入并允许修订；旧存档进入原阶段时不被新交互重复拦截。先验证这些表征是否正确，再润色移动、高亮与过渡。

课堂试用至少分开观察两类现象：学生会解释但点不到对象，属于操作问题；学生一路点亮对象却无法说明总量包含谁，属于表征或教学问题。可在不显示答案的可选变式中记录学生原话，并在稍后再次询问同类关系。样本、年级、是否求助及任务条件均须注明。

本研究未开展学生试验或产品测试。软件验收通过不能替代学习效果证据；本轮四份来源支持设计方向和限制条件，不证明v1.6能提高成绩、注意力或迁移能力。
