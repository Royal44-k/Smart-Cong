# 互动、学习伙伴与影视衔接 · 1.2

本稿与[分支剧本](02-branching-script.md)、[逐镜导演手册](13-director-production-bible.md)共同执行。故事以复述和理解过程为目标；实验以提出问题、只改一项、用记录解释为目标。新玩法服务这两种学习方式。

## 封面与路线

故事版用青绿，默认“完整学习”；实验版用深蓝，默认“称象练习”。切换版本时默认路线随之改变；学生仍能手选另一长度。封面在按钮旁说明当前路线，不能把短练习写成完整研究。已有进度保持原版本和长度；重开前能导出旧记录。

完整故事：看物品 → 小船试木块 → 画水线 → 找阿舟 → 连称重条 → 讲理由 → 分支结局 → 四格拼图与词义 → 我的小书。

完整实验：选问题与猜想 → 设计A/B → 操作与记录 → 解释变化 → 大船称量 → 分支结局 → 书箱迁移 → 我的报告。称象练习直接进入方案选择、留线、装船、称量与报告，适合读过课文后的复习。

## 交互执行表

|节点 / 视频接点|学生实际动作|错了怎样继续|教学证据与反馈|
|---|---|---|---|
|故事玩小船 / C-V03|先留猜想；点按钮或拖一块木块进船；可取走|超过金线时取走一块；猜想保留，不扣分|三块对齐才出现小鱼；曹冲说“金线碰到水面啦”|
|大船装载 / C-V07|石堆可点装、点取、拖上船；观察阿舟的位置|拖出船外不改变数量；已在船上的石堆再次拖入不卸下|同水线仍追问阿舟，不能把局部对齐当完整称量成功|
|故事称重 / C-V08|先点左列石堆称量；再点右列同图案的条；或从已称的石堆拖出连线|连错不记账，提醒看图案；重复连接只保留一笔|右列顺序打乱；成功留下可见曲线和勾号，刷新仍保留|
|四格故事 / C-V11|点卡依次放入，或拖入格子；拖动、左右箭头都可换位|先后排错可直接调整；不强迫全部撤回|顺序正确仍须选对“下沉”和“大象的重量”；小书记录真实讲述|
|完整实验台 / C-L02|拖木块到船上，或先点“拿一块”再点小船；数量按钮可直接调到1至5块|允许反复改条件、重新写A/B；两项一起变不能通过|船形随同一物理函数更新；只有两份可比较记录及正确解释才能继续|
|小象的找变化 / C-L02及短练习load页|展开可选小游戏，比较三组实际船图：木块、小人、水深|不限时、不扣分，错选给观察线索；答对后再看下一幅|每关只得一枚印章；三枚完成不解锁正式试验，也不替学生生成结论|

拖曳不是唯一操作方式。点选、按钮和键盘走同一判定；触屏误放和取消不扣进度。无速度排行榜。两版继续保留E1确认、E2修改、E3暂缓、E4待核对四种结尾，初次猜想、草稿和首次结尾不被覆盖。

## 角色表情与动作

|角色|平静 / 左上|思考 / 右上|开心 / 左下|鼓励 / 右下|
|---|---|---|---|---|
|小曹冲|双手自然、关注伙伴|手指近面颊、略歪头|微笑、竖拇指|伸出手掌、邀请再试|
|小象伙伴|鼻子轻垂、温和注视|歪头、鼻尖卷近面颊|抬鼻、轻举前脚|朝前伸鼻、温和迈步|

采用两张透明四表情图；[表情图集](../media/companions/gallery.html)、[角色提示词](../media/companions/prompts.json)、[文件清单](../media/companions/catalog.json)。页面以CSS定位使用原图，不重新生成不同脸或衣服。曹冲沿用青灰蓝交领衣、米白袖口、棕腰带和小发髻；小象为无象牙的蓝灰色幼象、粉色内耳。学习伙伴属于界面层；小象不是历史剧情中被称量的大象，不能混用体形和位置。

默认每3.8秒轻微起伏；成功时一次短点头或抬鼻姿态反馈。可暂停动作、收起伙伴、主动开启或关闭朗读；系统“减少动态”优先生效。文字和学习操作不依赖动画。朗读使用浏览器中文语音，是否有中文声音取决于本机；不自动播放，不计入19段影视对白音轨。

## 状态对应台词

|已经发生的动作|伙伴说什么|不能提前说什么|
|---|---|---|
|留了第一次猜想|“你的猜想留下了。动手看看，结果会不会和想的一样。”|猜想正确、已经会了|
|一堆实际称完|“这一堆称好啦！把它的称重条放到同样的图案旁边。”|全部称好了|
|一对称重条接好|“连好了！一堆石头对应一张称重条。”|整本记录完全正确|
|同线但阿舟仍在岸上|“水线碰到记号了。阿舟刚才在船上，现在在哪里？”|称象成功|
|阿舟回到船上|“你请阿舟回来了！两次的人一样了，再看看水线。”|不检查石堆便宣布成功|
|四卡正确排列|“四张图排顺了！试着用‘先、再、然后、最后’讲一讲。”|已经会讲故事|
|两份试验只改一项|“两次只改变了一项，可以比较了。你看到了什么？”|替学生选择发现|
|E2实际修正|“你找到问题，又改了一遍。现在记录与结论对上了！”|点击返回就算改对|

通用提示不改变关卡状态。模型只在主动提问时补充短线索；具体配置与限制见[伙伴接口说明](21-companion-api.md)。

## 视频生产接点与声音衔接

本轮沿用19个影视镜头、17张情境与人物采用图、38句对白、19段朗读与19份字幕；另增加两张界面伙伴图，共八种表情。新增玩法在视频停下后操作，不需要把每次拖曳预渲染成视频。

1. C-V03停在空载模型船和金线，不预演正确三块；学生放取后才出现小鱼和曹冲的对应表情。
2. C-V07停在象离船、阿舟取秤上岸的状态。不能把小象伙伴画进大船，也不能把阿舟上岸后的视频反复当当前状态播放。
3. C-V08展示分批称量工具；画面不给出已完成连线。视频结束接左右两列图案；线、勾号和称量记录均由学生产生。
4. C-V11展示四张待整理图卡，不在视频中排出最终答案。接可重排四格与动作词任务；返回调整时沿用这次书页。
5. C-L02停在实验桌与可操纵的小船。A/B两份记录、木块数量、人员、水深由实时界面决定。小游戏是可选观察练习，不出现在正式实验报告中冒充学生实验数据。
6. 伙伴保持页面右下的界面位置。视频/已有对白播放时避免伙伴朗读叠音；画面台词保留原角色声音，伙伴默认文字引导。回片时按现有字幕重新对齐，不把界面反馈烧进历史镜头。

制作验收：核对角色身份、表情四宫格、透明背景、视频首尾、各版入口、动作触发和回复取消。真实课堂中还需听学生讲述或解释，不能把三个印章当成理解证明。
