# 两种学习经历的重设计 · 1.1

这次修改针对“切换模式后仍在做同一套任务”。两版共享称象的科学事实与码头角色，但改变学生身份、任务组织、思考方式、操作表现和最终作品。课程依据见[教学研究](16-mode-pedagogy-research.md)。

## 有内容的趣味

1. 水线碰面的小鱼：孩子先留下猜想，再自己放三块让金线碰到水面；小鱼只在实际碰线时出现。奖励的是观察到关系。
2. 称重条找朋友：不能直接点完所有贴纸。先称这一堆，才得到它的图案条；贴错会提醒对应关系。卸下石头时收起本次称重条，旧草稿仍留下。
3. “咦，多了这一小堆”：可先装满五堆碰线，再发现阿舟不在船上。请回阿舟还要取走小堆，改变人物位置会改变船形。
4. 两次试验留下船形：A栏的轮廓作为虚线保留，A/B各有真实配置和船位。一起改两项无法说明原因，系统提醒学生重做对比，而非只选一句正确话。
5. 小书归自己：图序与两个关键词通过后，孩子口述或写下自己的表达。系统整理图卡；教师听实际讲述，不把自动图卡当成掌握证明。
6. 原先的我也留下：错猜不被覆盖，E4修正后保留首次结尾。E3/E4进入报告时明确保留待查事项，不把未验证数值印成定论。

## 文案规则

学生页优先使用“船身、装石头、称一堆、看阿舟、查记录、讲办法”。动作与看得见的对象放在一句话里。避免把“换载、证据链、状态门槛、等量代换”等专业术语放进低年级任务按钮。一次提示只帮一步，三层提示由孩子主动打开；错了提供可执行下一步，不评判聪明或品德。教师和制作文件保留必要术语。

故事不考大数输入；实验不是把故事数字加大。学段是产品建议，具体教材对接由教师根据本校用书安排。完整学习是新版主入口；称象练习保留为共用复习工具。旧存档继续原路线，重开才能进入新版，以免破坏已经完成的记录。
