课堂交付版 **1.8** · 2026-10-12。故事版与实验版分别完成“故事讲述”和“实验探究”，共享称象原理与码头角色。包含可运行课堂、图片与声音、教学资料、完整视频生产前期；实际视频由用户用外部工具制作。

## 启动与进度

双击“启动体验.cmd”，或在本目录运行 'node server.mjs'，打开 http://127.0.0.1:4184/ 。需要Node.js 24或以上，学生游玩不需安装其他依赖。本机服务只监听127.0.0.1；不要直接双击index.html。若端口占用，可先在PowerShell设置 '$env:CAOCHONG_PORT=4185'。

**保留旧进度。v1.7成果页可直接进入“出题给同桌”；旧记录自动补上新工坊字段，原图注、反思和首次结局保留。v1.6成果页可直接打开本轮展示，展示不写入新状态。v1.5存档可直接继续；新版回看和重量尺不追加通关门槛。v1.4存档可直接继续，进入完整学习的画线或实验阶段就能使用本轮改进。v1.3的完整故事可直接使用逐页讲述，新版实验修理也可在原路线中打开；需要重新体验完整路线时，可在封面选择“开始新版学习”，并先保存当前记录。** 新记录保留两版各自的学习过程。进度只保存在本机浏览器，可刷新继续；可随时在“我的发现袋/实验记录”保存JSON，供下载留档；目前不提供导入按钮。

## 两种完整学习

| |故事版 · 二至三年级|实验版 · 四至六年级|
|---|---|---|
|我是谁|曹冲的小帮手|小小研究员|
|我做什么|看物品、放木块、画线、找变化、贴称重条|选研究问题、留猜想、做A/B、核对称量、处理变化|
|我带走什么|四格小书、动作词和自己的讲述|实际两次记录、结论与待查项、书箱迁移、个人报告|
|建议节奏|约20分钟体验+8分钟分享|约30分钟体验+10分钟讨论；可分课|

时长是设计估计，按实际学生调整，无倒计时。四年级可在教师引导下安排对照；高年级逐步独立。共用“称象练习”适合复习，不代表两个完整教学版本。孩子可以错猜、返工、暂缓并说明下一步；结尾不作为聪明程度评分。

## 1.8 我出题，你来解

成果页新增“出题给同桌”。故事版由学生藏起一幅，另一位补回画面，再说这一步有什么用；可掀开纸帘求助。实验版由学生选择砝码、工具重量和工具在哪次上船，组成27种独立书箱题。先比较、再计算，核对后把自己的答案放回两次装载图，看哪里还差一份。每换一题就换一箱书，交棒后条件固定。

可同桌轮流，也可自己玩。没有倒计时或额外主线门槛；最近六次真实核对、修改和提示使用可查看、打印及导出，刷新可继续。

## 1.7 把作品讲给同学听

故事小书新增四页看图放映：孩子自己翻页，按需展开自己的话、参考讲法和同桌追问。实验报告新增四页研究会：原问题与猜想、实际A/B记录、称象结局和书箱迁移依次呈现。缺失留空，错误和暂定结论保留原样。展示期间伙伴安静陪候，返回后仍可编辑、打印；无计时、评分或额外通关门槛。

## 1.6 回看变化，把重量分成两份

故事“找变化”可在同一位置切换“第一次／这一次”，回看不会改动当前船况。实验书箱题压缩重复信息，新增可选重量尺：拖动、触摸、加减按钮和键盘都能分配320克总重量。原答案由学生自己填写；错误提示给出具体核对方向；改动试分会撤销过期肯定。记录册和打印只保留实际用过的分配。

## 1.5 把记号亲手留下，把试验放在一起看

故事“画记号”支持图上轻点、划线和键盘，选错物体会说明原因，取消不会误提交。实验桌改为操作与记录并排，手机顺序呈现；“摆试验—比记录—说发现”可随时定位。“照A/B摆回”帮助重看原条件，只有主动“记入”才覆盖记录。未填写的反思打印留白，保留学生原话。

## 已有玩法与伙伴

首页以青绿和深蓝区分版本，故事默认完整学习，实验默认称象练习；可手动切换。新增称重条连线、木块和石堆拖曳、四格重排、三关找变化。点选与键盘仍可完成同样任务。故事右下有小曹冲，实验右下有小象，真实操作触发表情与具体反馈；可以暂停、收起或开启朗读。

## 验证与维护

'npm test' 检查规则、分支、存档、图片哈希、声音和字幕。启动服务后执行 'npm run test:browser'，检查完整学习、纠错、键盘、小屏、兼容、打印、音轨与媒体回退。验收环境使用Playwright及Microsoft Edge；它们不是学生端依赖。

修改台词：先编辑media/shots.json，在有对应Windows中文语音的环境运行scripts/generate-dialogue.ps1，再执行 'node scripts/build-audio.mjs'、'node scripts/build-classroom-production.mjs'。构建依据镜头数据生成目录、任务表、字幕与导演手册，不再以旧模板覆盖新路线。视频回片后填写回片表、核验并设置src/media.mjs的video路径，再重跑流程测试。

旧版文件在工作目录留存；1.8交付清单以DELIVERY-MANIFEST.json为准。自动化验收证明功能与规则，开放表达和教学成效由课堂观察评价。
