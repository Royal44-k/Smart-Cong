# 项目说明与最新版本范围

本项目从“教科书故事—分支剧情—学生操作—不同结果—表达与反思”的制作流程出发，将《曹冲称象》做成可用于课堂的影游学习活动。当前正式交付为 v1.8.0；视频生成由外部工具完成，其余应用与制作资产按当前交付整理。

## 教学目标

故事版让低年级学生观察动作、理解“先留线，再替换、称量”的顺序，用自己的话讲清办法。实验版让高年级学生选择问题、比较两次条件、保留实际记录，并检验结论是否成立。共同关注等量替代、条件一致、证据表达和敢于改进。

学生可以猜错、返工、求助和修改，不用倒计时催促，也不把结局当作聪明程度评分。小曹冲与小象根据实际操作提供具体反馈，伙伴支持收起、暂停动态与按需朗读。

## 最新版能力

- 故事：看图找变化、图上留线、称重条连线、四格重排、自写讲述、作品放映、同桌藏图补图并解释作用。
- 实验：提出问题、A/B 对照、保存与摆回条件、修订结论、实验修理、书箱迁移、重量尺、研究展示及 27 种同桌出题。
- 共用：触摸与键盘操作、学习记录与打印、媒体降级文字、透明伙伴及服务端模型接口。
- 生产：统一采用图、镜卡、人物道具连续性、对白、朗读、字幕、提示词、互动接点和回片验收表。
